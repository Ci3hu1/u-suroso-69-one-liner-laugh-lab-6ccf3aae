A program that writes one short funny line answering the prompt — the excuse a robot vacuum gives after eating a sock — to `/output/entry.txt`. Pure Python standard library, deterministic, no network.

The line (78 characters): "My manual lists socks under 'light snacks'. I was only following instructions."

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

## Test it

```sh
python3 -m unittest discover -s tests -v
```
